# Whiteboard - Project Management

## Overview
Whiteboard is a university group project focused on planning an academic notification system to improve communication between students, instructors, and administrators.

The proposed system aims to provide timely notifications about assignments, exams, and grades through multiple channels, with notification preferences tailored to different user roles.

This repository contains the project planning report. It documents the proposed system and its management plan rather than a working software application.

## Project Objectives
- Address delayed academic notifications.
- Support notification delivery through multiple channels.
- Allow users to customize their notification preferences.
- Define the requirements, scope, schedule, responsibilities, and risks of the proposed project.

## Project Contents
The report includes:

- Introduction and problem statement.
- Proposed development methodology: Incremental Model.
- Project charter.
- Requirements collection techniques.
- Software, hardware, functional, and non-functional requirements.
- Scope statement.
- Work Breakdown Structure (WBS).
- WBS dictionary.
- RACI matrix.
- Gantt chart and project milestones.
- Risk register and risk matrix.
